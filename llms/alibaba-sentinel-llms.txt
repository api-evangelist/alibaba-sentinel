# Alibaba Sentinel

> Alibaba Sentinel is an open source flow control component for reliability, resilience, and monitoring of microservices. It provides flow control, traffic shaping, concurrency limiting, circuit breaking, and system adaptive overload protection, with a real-time dashboard for visualizing metrics and configuring rules dynamically. Written primarily in Java with a Go implementation (sentinel-golang), it integrates with Spring Cloud, Dubbo, gRPC, Apache RocketMQ, and Servlet.
